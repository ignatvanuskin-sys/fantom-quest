# Визуальный и ручной чек-лист

Автотесты (`npm test`) покрывают API, слоты, ночной график, валидацию, атомарность, админку и
базовые требования к вёрстке. Этот файл — то, что нужно проверить глазами и руками перед
публикацией. Он же — источник скриншотов для приёмки.

Сервер: `npm start` → `http://localhost:3000`.

---

```bash
npm start                    # терминал 1
npm run shots                # терминал 2 — полные скриншоты + замеры переполнения
npm run shots:first-screen   # читаемый предпросмотр первых экранов
```

`layout-report.md` и `layout-report.json`. Последний прогон: **66 замеров, 0 переполнений**.

## 2. Мастер записи

- [ ] Шаг 1 → 2 → 3 переключается, индикатор шагов подсвечивается
- [ ] «Дальше» на шаге 1 не пускает с составом 0 или 25 игроков
- [ ] Слоты подгружаются при выборе даты; видно количество свободных
- [ ] Ночные слоты помечены «после полуночи», в summary то же самое
- [ ] «Дальше» на шаге 2 без выбранного времени не пускает и объясняет почему
- [ ] Summary справа (снизу на мобильном) обновляется сразу: сценарий, дата, время, состав
- [ ] В summary цена показана как «Уточняется у администратора» — не выдуманное число
- [ ] Кнопка называется «Отправить заявку», а не «Оплатить»
- [ ] Успех: номер заявки, данные, текст про связь администратора, кнопка WhatsApp, телефон,
      «Проверить статус заявки»
- [ ] Ошибка сети: сообщение понятное, **введённые данные остались в форме**
- [ ] Занятый слот: сообщение «Время только что заняли», форма возвращается на шаг 2,
      сетка слотов перезагружается, данные сохранены
- [ ] Выход из «успеха» и повторная запись на другое время работает

## 3. Клавиатура и скринридер

Полный проход только с клавиатуры (`Tab`, `Shift+Tab`, `Enter`, `Space`, стрелки):

- [ ] Первый `Tab` — skip-link «Перейти к содержанию»
- [ ] Все интерактивные элементы получают видимый фокус
- [ ] Меню доступно, `aria-expanded` меняется
- [ ] Шаги мастера: `Tab` попадает в поля и кнопки линейно, ничего не пропущено
- [ ] Слоты: `Tab` заходит в группу, стрелки ←→↑↓ перемещают выбор, `Enter`/`Space` выбирают
- [ ] `aria-checked` меняется у выбранного слота
- [ ] Honeypot-поле не попадает в tab-порядок
- [ ] Сообщения об ошибках и успехе зачитываются (`aria-live`)
- [ ] `<details>` FAQ раскрываются с клавиатуры
- [ ] Модальных окон, ловушек фокуса и «прыгающего» фокуса нет

Скринридер (NVDA / VoiceOver):

- [ ] H1 объявляется один раз
- [ ] Поля имеют читаемые подписи и подсказки
- [ ] Ошибки полей связаны с полями (`aria-describedby`)
- [ ] Кнопки WhatsApp/телефон читаются осмысленно

## 4. Движение, звук, производительность

- [ ] После включения звука громкость плавно нарастает, после выключения — убирается
- [ ] Никакие видео, аудиофайлы и вся галерея не грузятся в критическом пути

- [ ] Нет бесконечных анимаций, дыма, jumpscare
- [ ] Ни один оверлей не блокирует hero, меню, скролл и кнопку записи

## 7. Админка

- [ ] Вход по неверному токену даёт понятную ошибку, а не пустой экран
- [ ] После перезагрузки страницы сессия сохраняется (кука)
- [ ] «Выйти» действительно разлогинивает
- [ ] Заявка: смена статуса меняет цвет метки, слот пересчитывается
- [ ] Кнопка WhatsApp открывает чат с готовым текстом подтверждения
- [ ] Закрытие слота: слот показывает «closed», на сайте он недоступен для записи
- [ ] Правка цены и возраста снимает плашки «Уточняется» на сайте
- [ ] Правка FAQ: заполненный ответ публикуется и попадает в разметку
- [ ] Отзыв без ссылки на источник остаётся черновиком и **не** попадает в Schema.org
- [ ] «Журнал» показывает действия без полных телефонов
- [ ] На мобильном таблица заявок превращается в карточки и читается

## 8. Граничные сценарии

- [ ] Игровой день, где часть слотов уже прошла: прошедшие помечены и недоступны
- [ ] Ночной слот 00:00 и 01:00 можно забронировать, в подтверждении — «после полуночи»
- [ ] Заявка ровно на 01:00 принимается (игра заканчивается в 02:00)
- [ ] Заявка на 02:00 отклоняется
- [ ] Переход через полночь при смене даты в селекте не путает игровой день
- [ ] Две вкладки бронируют один слот — вторая получает понятную ошибку
- [ ] Медленная сеть: кнопка «Отправляем…» блокируется, дублей заявки нет
- [ ] Сервер выключен во время отправки — сообщение об ошибке и сохранённые данные
- [ ] `MOCK_MODE=false` проверен на отдельном стенде (не на боевых данных)

## 9. Приёмка (Definition of Done)

Сайт готов, если новый посетитель без объяснений:

- [ ] понимает за 5 секунд: это хоррор-квест Fantom, где он находится и сколько длится игра;
- [ ] видит, как связаться, и находит кнопку записи;
- [ ] выбирает реальный слот меньше чем за минуту;
- [ ] отправляет заявку без потери данных;
- [ ] получает номер заявки и понимает, что будет дальше;
- [ ] не пугается интерфейса: ни одна анимация не прячет CTA, ни один слот не создаёт
      ложную срочность, ни одна цифра не расходится между UI, записью, разметкой и источником.
